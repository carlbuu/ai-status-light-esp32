# 使用指南

## 灯光状态

| 状态 | 灯光 |
| --- | --- |
| 任务运行中，任务数量动画关闭 | 黄灯常亮 |
| 1 个任务运行中，任务数量动画开启 | 黄灯常亮 |
| 2 个任务运行中，任务数量动画开启 | 黄灯连续闪 2 次后停顿并重复 |
| 3 个及以上任务运行中，任务数量动画开启 | 黄灯连续闪 3 次后停顿并重复 |
| 任一任务等待用户允许 | 绿灯闪烁 |
| 没有运行任务，但有已完成且尚未查看的项目 | 绿灯常亮 |
| 没有运行或待查看项目 | 自动熄灭 |
| 报错、断线或心跳超时 | 红灯常亮 |
| 电脑休眠 | 全部熄灭，唤醒后恢复当前状态 |
| 手动关闭显示 | 全部熄灭 |

多种状态同时存在时，优先级为：

```text
等待允许 > 工作中 > 报错 > 完成未查看 > 已查看/空闲
```

“按运行任务数量闪烁黄灯”默认关闭。关闭时，不论有多少个并行任务，黄灯都保持常亮。

## Codex 模式

- 用户 Hook 文件：`%USERPROFILE%\.codex\hooks.json`
- 程序还会监测 `%USERPROFILE%\.codex\sessions`，补充桌面版的开始、完成和授权状态。
- 多个 Codex 会话会分别计数。
- 等待授权时绿灯闪烁，并优先于任务数量动画。
- 程序读取 `%USERPROFILE%\.codex\.codex-global-state.json` 中的未读项目。项目黄点消失后，如果没有其他任务，灯会自动熄灭。

## Cursor 模式

- 用户 Hook 文件：`%USERPROFILE%\.cursor\hooks.json`
- 使用 Cursor 的会话、提示词、工具、Shell、MCP 和停止事件统计任务。
- 为准确显示等待允许，Shell、MCP、网页搜索和网页读取操作会通过 Hook 返回 `ask`，因此 Cursor 会弹出权限提示。
- 切换回 Codex 后，上述权限 Hooks 会自动移除。
- 程序只读查询 Cursor 的 `composerHeaders.hasUnreadMessages`，同步待检查项目。
- 如果完成时对应对话已打开，绿灯会亮约 3 秒；未读项目仍会让绿灯保持常亮。

Cursor Hooks 参考：[官方文档](https://cursor.com/cn/docs/hooks)。

## 控制面板

控制面板提供：

- Codex/Cursor 单选与一键配置；
- 自动或手动串口选择；
- 连接、断开和重新扫描；
- 设备、固件、AI 和显示状态；
- 灯光测试；
- 5%～100% 实时亮度调节；
- 任务数量动画和开机启动开关；
- 待检查项目数量与“全部标记已检查”；
- 关闭显示和退出程序。

亮度、当前平台和任务数量动画设置保存在：

```text
%LOCALAPPDATA%\CodexStatusLight\settings.json
```

“全部标记已检查”只让状态灯忽略当前未读项，不会修改或删除 Codex/Cursor 中的项目。

## 窗口与托盘

- 窗口缩放时，字体、按钮和间距会同步调整。
- 窗口变窄时，状态区和设置区会自动换行；高度不足时可以滚动。
- 点击窗口右上角关闭只会隐藏到系统托盘。
- 真正退出请使用界面的“退出程序”或托盘菜单中的“退出”。
- “关闭显示”后桥接程序仍发送心跳，避免设备因心跳超时亮红灯。

## 配置安全

- 修改 Hooks 前会创建 `.backup-yyyyMMdd-HHmmss-fff` 备份。
- 程序只删除命令中包含本程序 EXE 的 Hooks。
- 开机启动只作用于当前 Windows 用户。
- 电脑休眠前会关闭灯光；唤醒后恢复状态或重新扫描串口。
