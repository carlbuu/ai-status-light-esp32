# 故障排查

## 一直亮红灯

依次检查：

1. ESP32-C3 是否已经烧录本项目固件。
2. USB 线是否支持数据传输。
3. Arduino IDE 串口监视器或其他串口工具是否已经关闭。
4. 控制面板是否显示正确的 COM 口。
5. 点击“刷新端口”，再点击“连接设备”。

固件约 7 秒未收到有效命令会进入红灯错误状态。Windows 程序连接成功后每 2 秒发送一次心跳。

## AI 状态不变化

- 点击“应用并配置”后，必须完全退出并重新打开所选平台。
- 确认界面中选择的平台与正在使用的平台一致。
- 切换平台时再次点击“应用并配置”。未选中的平台不会控制灯光。

## 亮度滑块无效

- 固件版本 4 和 5 支持亮度命令。
- 休眠自动熄灯需要固件版本 5。
- 如果界面显示旧固件，请重新烧录仓库中的最新固件。
- “关闭显示”始终会完全熄灭，不受最低亮度限制。

## Cursor 频繁询问工具权限

这是 Cursor 模式用于显示绿色“等待允许”闪烁的预期行为。Shell、MCP、网页搜索和网页读取操作会进入 `ask`。切换回 Codex 并点击“应用并配置”后，相关 Hooks 会被移除。

## 无法取消开机启动

取消勾选“开机自动启动”，然后点击“应用并配置”。程序会同时清理当前注册表项和旧版本可能遗留的启动文件夹项目。

## 关闭窗口后程序仍在运行

这是系统托盘常驻设计。请使用界面的“退出程序”按钮，或右键托盘图标选择“退出”。

## 找不到设备或端口

- 确认 Arduino IDE 中 **USB CDC On Boot** 为 **Enabled**。
- 重新插拔 USB 线并点击“刷新端口”。
- 检查设备管理器中是否出现串口。
- 关闭所有可能占用串口的软件。
- 自动扫描会优先尝试 COM15，再扫描其他端口；也可以手动指定端口。

## 查看日志

右键托盘图标选择“打开日志”，或直接查看：

```text
%LOCALAPPDATA%\CodexStatusLight\bridge.log
```

提交问题时，建议附上软件版本、固件版本、Windows 版本、所选平台、复现步骤和脱敏后的相关日志。
