AI 工作状态指示灯 - 一键图形版
================================

另一台 Windows 电脑只需复制 CodexStatusLight-OneClick.exe。

1. 双击 EXE 打开控制面板。
2. 在“选择 AI 平台”中选择 Codex 或 Cursor。
3. 按需勾选“按运行任务数量闪烁黄灯”和“开机自动启动”；两个选项默认均不强制开启。
4. 点击“应用并配置”。
5. 完全退出并重新打开所选平台，让 Hooks 生效。
6. 在“设备连接”中选择“自动扫描”或指定 COM 口，然后点击“连接设备”。
7. 在“灯光测试”中拖动亮度滑块，可在 5%～100% 之间实时调节；程序会自动保存亮度。

切换平台
--------
重新打开控制面板，选择另一个平台，再点击“应用并配置”。
程序只允许一个平台生效；会移除旧平台中属于本程序的 Hooks，
并保留 Codex 和 Cursor 中其他已有的 Hooks。

Cursor 特别说明
---------------
Cursor 模式使用官方 Hooks。为了让“等待允许”的绿灯准确闪烁，
Shell、MCP、网页搜索和网页读取操作会要求 Cursor 弹出允许提示。
程序会按不同会话和任务分别计数；正常完成后，仍带黄点的项目会保持绿灯常亮。
如果完成时 Cursor 对话已经打开，绿灯会亮约 3 秒作为完成提示。
切换回 Codex 后，这些提示 Hooks 会自动移除。

灯光定义
--------
- 默认关闭“按运行任务数量闪烁黄灯”：任意数量任务运行时黄灯常亮
- 开启该选项后：1 个任务黄灯常亮，2 个任务双闪，3 个及以上任务三闪
- 请求权限：绿灯闪烁
- 已完成但项目尚未点击（仍有黄点）：绿灯常亮
- 所有完成项目已点击，且没有运行任务：自动熄灯
- 报错/断线：红灯常亮
- 关闭显示：全部熄灭

亮度调节
--------
- 固件版本 4 支持 GPIO2、GPIO3、GPIO4 硬件 PWM 调光，无需重新接线。
- 亮度范围为 5%～100%，所有常亮、双闪、三闪及权限闪烁都会使用该亮度。
- “关闭显示”不受最低亮度限制，仍会完全熄灭。
- 如果界面提示固件过旧，请重新烧录本项目的 ESP32-C3 固件。

完成项目与自动熄灯
------------------
- Codex 或 Cursor 项目完成后，如果项目仍带黄点，绿灯保持常亮。
- 点击对应项目后，程序会读取已读状态；没有其他运行或待检查项目时自动熄灯。
- 多个完成项目中只点击一个时，其余黄点仍会让绿灯保持常亮。
- “全部标记已检查”可作为备用操作，只影响状态灯，不会删除项目。

窗口和退出
----------
- 放大或缩小窗口时，内容会同步缩放或换行；高度不足时可以滚动。
- 点击右上角关闭只是隐藏到托盘。
- 真正退出请点击“退出程序”或使用托盘右键菜单。
- 取消“开机自动启动”并应用后，会清理新版和旧版遗留的启动项。

ESP32-C3 必须已烧录本项目固件，USB CDC On Boot 必须为 Enabled。
