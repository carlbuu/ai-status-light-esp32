移植到另一台 Windows 电脑
==========================

方式一：直接复制 CodexStatusLight-OneClick.exe（推荐）
1. 双击 EXE。
2. 选择 Codex 或 Cursor。
3. 按需选择是否开机启动。
4. 点击“应用并配置”。
5. 完全退出并重新打开所选平台。

方式二：使用便携 ZIP
1. 解压 CodexStatusLight-portable.zip。
2. 双击“安装到此电脑.cmd”。
3. 默认沿用这台电脑上次选择的平台；第一次安装默认 Codex。
4. 安装后也可以在控制面板中随时切换到 Cursor。

安装程序会：
- 将 EXE 复制到当前用户的 LocalAppData\CodexStatusLight。
- 配置当前选中的 Codex 或 Cursor 用户 Hooks。
- 移除旧平台中属于本程序的 Hooks。
- 保留两个平台中其他已有的 Hooks。
- 修改 Hook 文件前创建带时间戳的备份。
- 按选择设置或取消当前用户的开机启动项。

卸载
----
双击“卸载.cmd”。卸载会同时清理本程序在 Codex 和 Cursor 中的
Hooks、开机启动项和已安装 EXE，不会删除其他 Hooks。

要求
----
- Windows 10/11
- ESP32-C3 已烧录本项目固件
- USB CDC On Boot 为 Enabled
- Arduino IDE 串口监视器已关闭

Cursor 模式会让 Shell、MCP、网页搜索和网页读取操作弹出允许提示，
这是显示绿色“等待允许”闪烁所必需的行为；切换回 Codex 后会自动移除。

多任务灯光
----------
- 1 个运行任务：黄灯常亮
- 2 个运行任务：黄灯双闪
- 3 个及以上运行任务：黄灯三闪
- 任一任务请求权限：绿灯闪烁
- 有已完成但未点击的黄点项目：绿灯常亮
- 全部完成项目已点击且没有运行任务：自动熄灯

亮度调节
--------
- 控制面板可在 5%～100% 之间实时调节亮度并自动保存。
- ESP32-C3 必须烧录版本 4 固件；GPIO2、GPIO3、GPIO4 接线保持不变。
- 旧版固件仍可连接和显示状态，但不支持亮度滑块。

待检查项目
----------
- Codex 和 Cursor 的黄点/未读项目会显示在控制面板的“待检查项目”数量中。
- 点击最后一个黄点项目后，如果没有运行任务，灯会自动熄灭。
- “全部标记已检查”只让灯忽略当前黄点，不会修改平台中的项目。
